# DFLAB Backup Procedure

**Document ID:** DFLAB-INF-ST-003 · **Version:** 1.0 · **Status:** Procedure framework; implementation pending

## Objective
Establish an independent, recoverable backup for selected laboratory records and data. Define scope, schedule, destination, access and retention before routine operation.

## Procedure framework

1. Identify data approved for backup and its sensitivity/classification.
2. Select a physically independent destination; the same primary device is not an independent backup.
3. Record device identity and confirm sufficient capacity and health.
4. Copy data using an approved method; record date, operator, scope and any errors.
5. Verify the backup using appropriate file counts, logs and cryptographic hashes where suitable.
6. Protect the backup from unauthorized access and accidental modification.
7. Record retention, storage location and responsible custodian in a controlled record.
8. Schedule recovery tests and document results.

Do not store credentials or recovery keys in this public file. Do not claim that a backup exists until a real backup operation and verification have been recorded. Recovery testing is documented separately.
